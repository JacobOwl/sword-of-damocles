# Credits

## Drawn for this library

Everything under made/ was drawn for this project in code (tools/), in the game's own styles. Those files are the project's own, on the same terms as the game. The maps are built on open data:

- Coastlines and rivers: [Natural Earth](https://www.naturalearthdata.com/), public domain.
- Ancient site positions: [Pleiades](https://pleiades.stoa.org/), CC BY 3.0. Credit line on every map that uses it: "Sites: Pleiades, CC BY 3.0."
- Syracuse coast and cliffs: [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors, ODbL. Keep the line "(c) OpenStreetMap contributors, ODbL" on the Syracuse map or wherever it is shown.

The data came by way of the phoenician-punic-world project's prepared files (tools/prep-data.mjs).
