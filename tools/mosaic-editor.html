Carthage Mosaic Editor

Make a portrait for anyone in the game, see the whole cast at once, paint by hand, turn a coin photo into a mosaic, or lay the coastline map in stone. Every colour comes from a fixed palette, so the pictures sit together. Save one picture, or the whole cast as a zip at game sizes.

The cast

The 24 people in the game’s data, each in their faction’s colours. Click a portrait to change it. Changes are kept in this browser; save the looks file to keep them for good.

Sizes to save

The zip holds one picture per person and size, named by the person’s id in the game’s data (for example dionysius-256.png), and looks.json, which reopens the whole cast here under Save, Open saved settings. Below about 128 px the tiles blur together; raise the tile size for small pictures.

Coin and colours

The names are Claude’s spellings in Greek capitals and have not been checked. Syracusan coins of this time name the city, ΣΥΡΑΚΟΣΙΩΝ, not a ruler, so a name here is invention.

Every look is invention: no source describes these faces. Faction colours are a first suggestion and yours to change.

Map

0 lays the sea in straight rows. Higher numbers let more rows follow the shore. The top setting ripples all the way out.

The city list on these maps is a first draft and has not been checked against the site's place records. Coastlines are modern; some ancient shores have moved, and Utica, once a port, now sits inland.
