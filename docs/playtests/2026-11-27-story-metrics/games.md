# Story metrics: every game

600 games of the Second island test, 30 seasons each, written by `node scripts/story-metrics.ts`. The numbers are in [results.md](results.md). Kinds: rises = a man climbs to rival or pretender; seats = a seat lost and won back; turncoats = a friend or kinsman turns plotter; reversals = a reversal; deaths = a named death; warnings = a warning that came true; wars = a war begun and ended; exiles = an exile and a return.
